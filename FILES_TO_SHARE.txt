⚙️ ENVIRONMENT SETUP (For Team Member)
================================================================================

Requirements:
- Python 3.10+ 
- NVIDIA GPU (8GB+ VRAM)
- CUDA 11.8+
- ~20GB disk space (for model download)

Setup Commands:
```
# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install fastapi uvicorn torch torchaudio transformers accelerate

# Download MOSS-TTS models (one-time, ~16GB)
python3 -c "from transformers import AutoModel; AutoModel.from_pretrained('OpenMOSS-Team/MOSS-TTS-Realtime')"

# Start server
python3 realtime_tts_server.py
```

📞 SUPPORT RESOURCES
================================================================================

If team member has issues:

1. Check TEAM_INTEGRATION_GUIDE.md → Troubleshooting section
2. Run: curl http://localhost:8002/health
3. Check server logs
4. Review TECHNICAL_SUMMARY.md for performance expectations
5. Run test suite: python3 test_streaming_client.py

Common Issues:
- "Server not found" → Check firewall, port 8002 open
- "Out of memory" → Reduce concurrent sessions in code
- "Voice not found" → Verify voice files exist in voice_samples/
- "Slow response" → Check GPU usage, cache hit rate in metrics
